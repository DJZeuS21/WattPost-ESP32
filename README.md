# WattPost

**Українська** · [English](README.en.md)

WattPost — прошивка для ESP32, що зчитує показники акумулятора з JK BMS через Bluetooth LE та показує їх у браузері. ESP32 розміщується поруч із батареєю; телефон або комп’ютер відкриває її стан у домашній Wi-Fi-мережі.

Локальний моніторинг та історія працюють без акаунта й інтернету. Для перегляду поза домашньою мережею можна підключити необов’язковий WattPost Cloud.

## Що можна побачити

- **Поточний стан:** заряд, розряд або очікування, відсоток заряду, напруга, струм, потужність і залишкова ємність.
- **Комірки та температури:** напруга кожної комірки, мінімум, максимум, розбіг напруг і доступні датчики температури.
- **Історія до 14 днів:** 10-хвилинні усереднені записи у Flash-пам’яті ESP32, що зберігаються після перезавантаження. Добові підсумки енергії, графіки з масштабуванням та погодинний профіль навантаження.
- **Налаштування BMS:** перегляд зчитаних параметрів захисту, балансування, струмових і температурних обмежень. Цей екран не змінює параметри BMS.
- **Доступ із телефона:** той самий вебінтерфейс адаптується до вузького екрана; окремий застосунок не потрібен.

## Що потрібно для запуску

- **Класична ESP32 з 4 МБ Flash:** наприклад, ESP32-WROOM-32 / ESP32-WROOM-32D DevKit із USB. Потрібні USB-кабель для передачі даних і живлення від звичайного 5 В USB-адаптера. ESP32-C3 та ESP32-S3 для цієї збірки не підходять.
- **Акумулятор із сумісною JK BMS та Bluetooth LE.** Наявність Bluetooth сама по собі не гарантує сумісності: вона залежить від моделі й протоколу. Скріншоти показують лише демонстраційний приклад, а не перелік перевірених моделей.
- **Wi-Fi 2,4 ГГц** та комп’ютер для першого запису прошивки через USB.

WattPost не потребує дротового підключення до BMS для читання телеметрії. Звільніть Bluetooth-з’єднання BMS перед підключенням ESP32: застосунок JK на телефоні може утримувати його зайнятим.

> [!WARNING]
> WattPost — система моніторингу, яка не замінює захист JK BMS. Не підключайте піни ESP32 безпосередньо до силових клем акумулятора.

## Встановлення та перший запуск

1. Завантажте **`WattPost-ESP32-full.bin`** із [Releases](https://github.com/DJZeuS21/WattPost-ESP32/releases).
2. Запишіть повний образ через USB за адресою **`0x0`**, дотримуючись [покрокової інструкції](docs/INSTALLATION.md). Збирати код самостійно не потрібно.
3. Підключіться до Wi-Fi **`WattPost-XXXX`** з паролем **`12345678`** і відкрийте **http://192.168.4.1/**. У майстрі виберіть домашню мережу й JK BMS; BMS можна додати й пізніше.
4. Поверніться до домашнього Wi-Fi та відкрийте **http://bms.local/** або IP-адресу ESP32.

Якщо пристрій не знаходиться або немає даних, дивіться [розділ усунення проблем](docs/INSTALLATION.md#8-типові-запитання-та-вирішення-проблем).

## Як це працює

<picture>
  <source media="(max-width: 640px)" srcset="docs/diagrams/how-it-works-uk-mobile.svg">
  <img src="docs/diagrams/how-it-works-uk.svg" alt="Як працює WattPost: JK BMS — Bluetooth LE — ESP32 — Wi-Fi — браузер" width="1200">
</picture>

1. **JK BMS** постійно контролює стан батареї та надає телеметрію підключеному пристрою через Bluetooth Low Energy (BLE).
2. **ESP32** з прошивкою WattPost підключається до BMS по повітрю, обробляє пакети даних і записує історію. Для отримання телеметрії ESP32 не потрібно підключати проводами до силових клем акумулятора.
3. **Локальний вебінтерфейс** доступний із телефону або комп’ютера в домашній мережі за адресою `http://bms.local/` (або IP-адресою ESP32).

## Локальний і хмарний доступ

| Параметр | Локальний режим (WattPost Local) | Хмарний доступ (WattPost Cloud) |
|:---:|:---:|:---:|
| **Адреса** | `http://bms.local/` або локальна IP | [wattpost.pp.ua](https://wattpost.pp.ua) |
| **Реєстрація** | **Не потрібна** | Потрібен безкоштовний акаунт |
| **Інтернет** | **Не потрібен** (працює автономно) | Потрібен для віддаленого перегляду |
| **Конфіденційність** | Дані залишаються локально, якщо ви не ввімкнули Cloud | Дані передаються до WattPost Cloud |
| **Віддалений доступ** | Лише всередині Wi-Fi мережі | З будь-якої точки світу через інтернет |
| **Кілька пристроїв** | Окремо на кожному пристрої | Моніторинг кількох ESP32 в одному кабінеті |
| **Оновлення (OTA)** | Через підключений WattPost Cloud | Автоматичні або ручні підписані оновлення |

> [!NOTE]
> Локальний вебінтерфейс є повнофункціональним і незалежним. Підключення до WattPost Cloud є **повністю добровільним**. Якщо хмара або інтернет недоступні, ESP32 продовжує зчитувати показники BMS і зберігати історію локально.

## Оновлення прошивки

Після першого запису через USB офіційні оновлення можна встановлювати через WattPost Cloud, коли ESP32 має інтернет. Пристрій перевіряє підпис перед встановленням; два розділи прошивки дають змогу повернутися до попередньої версії, якщо нова не пройде перевірку запуску.

Вихідні тексти прошивки та локального вебінтерфейсу знаходяться в каталозі [`esp32_monitor/`](esp32_monitor/).

- Хмарний бекенд WattPost Cloud є окремим пропрієтарним сервісом і не входить до складу цього репозиторію.
- Інформація про походження бінарних файлів та контрольні суми офіційного релізу доступна в [довідці про реліз](docs/RELEASE_PROVENANCE.md).
