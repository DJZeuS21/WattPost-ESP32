# Як встановити WattPost на ESP32

[← Головна сторінка](../README.md) · **Українська** · [English](INSTALLATION.en.md)

Ця інструкція написана для користувачів, які ніколи раніше не прошивали мікроконтролери. Усе налаштування виконується без програмування та без пайки: ESP32 зв'язується з JK BMS виключно бездротово через Bluetooth Low Energy.

---

## 1. Що знадобиться для встановлення

- **Плата розробника ESP32**  
  Потрібна класична плата **ESP32-WROOM-32** або **ESP32-WROOM-32D DevKit** із **4 МБ Flash-пам'яті** та вбудованим USB-роз'ємом (Micro-USB або Type-C).  
  *Не підходять: плати без USB (bare-модулі), плати з іншими чіпами (ESP32-C3, ESP32-S3 тощо — наразі потрібна класична ESP32).*
- **Акумулятор із сумісною JK BMS**  
  Будь-яка сучасна JK BMS (JK-B1A..., JK-B2A..., JK-BD... тощо) із підтримкою **Bluetooth LE**.
- **USB-кабель із лініями передачі даних (Data Cable)**  
  *Важливо: дешеві кабелі «тільки для заряджання» не передають дані через USB і комп'ютер не побачить плату.*
- **Комп’ютер** з операційною системою Windows, Linux або macOS.
- **Домашня Wi-Fi-мережа 2,4 ГГц** (ESP32 підтримує стандарт 802.11 b/g/n 2,4 ГГц; мережі 5 ГГц не підтримуються апаратно).

ESP32 живиться від будь-якого стандартного USB-блока живлення на 5V (1A або більше). З'єднувати ESP32 дротами з високовольтними клемами акумулятора **суворо заборонено**.

---

## 2. Завантажте файл прошивки

Перейдіть у розділ **[GitHub Releases](https://github.com/DJZeuS21/WattPost-ESP32/releases)** і завантажте файл:

👉 **`WattPost-ESP32-full.bin`**

Це єдиний готовий монолітний образ для першого запису через USB: він уже об'єднує завантажувач (bootloader), таблицю розділів (partition table), початкові дані OTA та саму прошивку WattPost. Вам не потрібно завантажувати кілька різних файлів чи вираховувати адреси зміщення.

> [!NOTE]
> Цей повний образ призначений для **первинного встановлення на нову плату**. Якщо на вашому пристрої вже встановлено WattPost, подальші оновлення здійснюються автоматично або кнопкою в інтерфейсі через штатний механізм OTA без підключення до комп'ютера.

---

## 3. Під'єднайте ESP32 до комп’ютера

Підключіть ESP32 через USB і визначте номер віртуального COM-порту:

- **Windows**: натисніть правою кнопкою миші на «Пуск» → «Диспетчер пристроїв» → розкрийте «Порти (COM і LPT)». Ви побачите запис на зразок `Silicon Labs CP210x USB to UART Bridge (COM3)` або `USB-SERIAL CH340 (COM4)`. Запам'ятайте номер порту (наприклад, `COM3` чи `COM4`).
- **Linux**: відкрийте термінал і виконайте `ls /dev/ttyUSB* /dev/ttyACM*`. Зазвичай пристрій з'являється як `/dev/ttyUSB0` або `/dev/ttyACM0`.
- **macOS**: порт з'явиться у вигляді `/dev/cu.usbserial-...` або `/dev/cu.SLAB_USBtoUART`.

> [!TIP]
> Якщо комп'ютер не реагує на підключення або показує невідомий пристрій, установіть драйвер мікросхеми USB-UART, яка встановлена на вашій платі:
> - Для чіпа **CP2102 / CP2104**: [офіційний драйвер Silicon Labs CP210x VCP](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers)
> - Для чіпа **CH340 / CH341**: [офіційний драйвер WCH CH340](https://www.wch-ic.com/downloads/CH341SER_ZIP.html)

---

## 4. Запишіть прошивку через USB

Для прошивки використовується офіційна відкрита утиліта від виробника чіпа Espressif — **`esptool`**.

1. Переконайтеся, що на комп'ютері встановлено [Python](https://www.python.org/downloads/) (версія 3.8 або новіша). Під час встановлення на Windows обов'язково поставте прапорець **«Add python.exe to PATH»**.
2. Відкрийте командний рядок (Terminal або PowerShell) і перейдіть у папку, куди ви завантажили `WattPost-ESP32-full.bin`.
3. Установіть утиліту `esptool`:
   ```bash
   pip install esptool
   ```
4. Запустіть запис прошивки. Замініть `PORT` на назву вашого порту (наприклад, `COM4` на Windows або `/dev/ttyUSB0` на Linux):
   ```bash
   python -m esptool --chip esp32 --port PORT --baud 460800 write-flash --flash-mode dio --flash-freq 40m --flash-size 4MB 0x0 WattPost-ESP32-full.bin
   ```
   *(На Linux або macOS використовуйте `python3` замість `python`).*

5. **Зверніть увагу на адресу `0x0`**: оскільки файл `WattPost-ESP32-full.bin` є повним образом Flash-пам'яті, його записують із нульового байта.
6. Зачекайте 20–30 секунд до появи повідомлення **«Hash of data verified. Leaving... Staying in bootloader»**.
7. Натисніть кнопку **EN** (або **RESET**) на платі ESP32 для її перезапуску у звичайному робочому режимі.

> [!TIP]
> Якщо `esptool` пише «A fatal error occurred: Failed to connect to ESP32: No serial data received»:
> 1. Спробуйте зменшити швидкість передачі з `460800` до `115200` (параметр `--baud 115200`).
> 2. На деяких платах під час появи напису `Connecting.....` потрібно натиснути й утримувати апаратну кнопку **BOOT** на платі протягом 2-3 секунд, доки не почнеться запис, після чого відпустити.

## 5. Перше налаштування Wi-Fi та JK BMS

Після першого старту ESP32 розгортає власну точку доступу Wi-Fi для швидкого налаштування через смартфон або ноутбук.

![Майстер першого налаштування WattPost](screenshots/first-setup.png)
*Екран майстра налаштування WattPost (First Setup)*

1. Відкрийте список доступних Wi-Fi мереж на телефоні чи комп'ютері.
2. Знайдіть мережу **`WattPost-XXXX`** (де XXXX — унікальні символи вашого модуля).
3. Підключіться до неї. Пароль за замовчуванням: **`12345678`**.
4. У більшості смартфонів автоматично відкриється вікно входу (Captive Portal). Якщо цього не сталося, відкрийте браузер і перейдіть на:  
   👉 **http://192.168.4.1/**
5. Натисніть **«Почати»**:
   - **Крок 1 — Wi-Fi**: виберіть вашу домашню мережу 2,4 ГГц зі списку (або натисніть «Сканувати»), введіть її пароль і натисніть «Підключити». ESP32 перевірить правильність пароля та отримає IP-адресу у вашій домашній мережі.
   - **Крок 2 — JK BMS**: майстер почне Bluetooth-пошук. Виберіть вашу JK BMS зі списку знайдених пристроїв і підтвердьте вибір.
6. Натисніть **«Завершити»**. ESP32 збереже конфігурацію, вимкне тимчасову мережу налаштування й перейде в штатний режим роботи.

> [!IMPORTANT]
> **Важливе правило Bluetooth JK BMS:**  
> Більшість моделей JK BMS здатні підтримувати **лише одне активне Bluetooth-з'єднання одночасно**. Якщо в цей момент на вашому телефоні відкрито офіційний мобільний додаток JK BMS, закрийте його та вимкніть зв'язок у додатку, інакше BMS буде зайнята і ESP32 не зможе до неї під'єднатися.

## 6. Локальний перегляд (http://bms.local/)

Після завершення налаштування поверніть смартфон або ПК до вашої звичайної домашньої Wi-Fi-мережі та відкрийте в браузері:

🌐 **http://bms.local/**

Ви побачите головну панель WattPost із поточним станом акумулятора!

### Що робити, якщо bms.local не відкривається?
Адреса `bms.local` працює за технологією mDNS (Bonjour / Avahi). Більшість пристроїв Apple, Linux, сучасних Windows 10/11 та Android підтримують її автоматично.  
Якщо у вашій мережі `bms.local` не резолвиться:
1. Подивіться IP-адресу, яку роутер видав пристрою ESP32 (її показує майстер налаштування на останньому кроці, або панель керування вашого домашнього роутера — пристрій матиме ім'я `wattpost` або схоже).
2. Відкрийте інтерфейс прямо за цією IP-адресою: наприклад, **`http://192.168.1.120/`**.
3. Рекомендуємо закріпити статичний IP за MAC-адресою ESP32 в налаштуваннях DHCP вашого роутера.

## 7. Підключення до WattPost Cloud (необов'язково)

Якщо ви бажаєте переглядати параметри акумулятора перебуваючи поза домом:
1. Зареєструйте безкоштовний обліковий запис на сайті **[wattpost.pp.ua](https://wattpost.pp.ua)**.
2. У вебінтерфейсі WattPost перейдіть у вкладку «Налаштування» → розділ «WattPost Cloud».
3. Натисніть «Підключити пристрій» і слідуйте підказкам на екрані.

Хмарний сервіс також дає змогу бачити кілька батарей в одному кабінеті та отримувати автоматичні безпечні оновлення прошивки повітрям (OTA).

## 8. Типові запитання та вирішення проблем

| Симптом | Можлива причина | Що зробити |
|---|---|---|
| Комп'ютер не бачить порт ESP32 | Кабель тільки для заряджання або немає драйвера | Спробуйте інший USB-дріт; установіть драйвер CP2102 або CH340. |
| esptool видає помилку підключення | Плата не перейшла в режим завантажувача | Затисніть кнопку BOOT під час з'єднання; зменшіть швидкість до 115200. |
| Не з'являється мережа WattPost-XXXX | Нестача живлення або збій запису | Перевірте USB-кабель і блок живлення (потрібно не менше 1A 5V); натисніть EN/RESET. |
| Телефон пише «Немає інтернету» в мережі WattPost-XXXX | Це нормальна поведінка локальної мережі | Залишайтеся підключеними до неї; вимкніть мобільний інтернет на телефоні на час налаштування. |
| JK BMS не знаходиться під час сканування | BMS зайнята іншим телефоном або занадто далеко | Закрийте додаток JK BMS на смартфоні; переконайтеся, що ESP32 знаходиться в радіусі дії BLE (до 5–10 м). |
| Не відкривається bms.local | Мережа не підтримує mDNS або телефон у гостьовій мережі | Переконайтеся, що ви в одній підмережі Wi-Fi 2,4 ГГц; відкрийте за прямою IP-адресою (наприклад, `http://192.168.1.50/`). |
| Дані BMS зникли («Очікування BMS») | Акумулятор вимкнено або зникло живлення BMS | Перевірте вимикач батареї; перевірте, чи не відкрив хтось мобільний додаток JK на іншому телефоні. |
