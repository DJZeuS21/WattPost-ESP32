# Як встановити WattPost на ESP32

[← Головна сторінка](../README.md) · **Українська** · [English](INSTALLATION.en.md)

Ця інструкція для тих, хто раніше не працював з ESP32. Паяти нічого не потрібно: ESP32 отримує дані від JK BMS через Bluetooth.

## 1. Що придбати й підготувати

- **ESP32-WROOM-32D DevKit** або сумісну класичну плату ESP32 із **4 МБ Flash** та USB-портом. Обирайте готову плату розробника, а не окремий модуль без USB.
- Акумулятор із сумісною **JK BMS**, що підтримує **Bluetooth Low Energy (BLE)**.
- **USB-кабель із передаванням даних**. Кабель лише для заряджання не підійде.
- Комп’ютер із Windows, Linux або macOS для першого встановлення.
- Домашню **Wi-Fi-мережу 2,4 ГГц**.

ESP32 можна живити звичайним USB-адаптером. Не потрібно підключати її дротами до акумулятора чи BMS.

## 2. Завантажте прошивку

Відкрийте [GitHub Releases](https://github.com/DJZeuS21/WattPost-ESP32/releases) і завантажте пакет прошивки **для класичної ESP32 із 4 МБ Flash**.

Поточна збірка WattPost використовує чотири файли:

| Файл | Адреса запису |
| --- | --- |
| `bootloader/bootloader.bin` | `0x1000` |
| `partition_table/partition-table.bin` | `0x8000` |
| `ota_data_initial.bin` | `0xF000` |
| `wattpost_mini.bin` | `0x20000` |

Розпакуйте всі файли в одну папку, **зберігши підпапки**.

**Це спосіб першого встановлення на нову плату.** Якщо на ESP32 уже є WattPost, налаштування або історія, використовуйте штатне оновлення OTA. Не перепрошивайте її повним набором файлів без резервної копії та плану збереження даних.

## 3. Під'єднайте ESP32 через USB

Під'єднайте ESP32 до комп’ютера й знайдіть її послідовний порт:

- **Windows:** «Диспетчер пристроїв» → «Порти (COM і LPT)» → наприклад `COM4`.
- **Linux:** зазвичай `/dev/ttyUSB0` або `/dev/ttyACM0`.
- **macOS:** зазвичай `/dev/cu.usbserial-…` або `/dev/cu.SLAB_USBtoUART`.

Якщо порт не з’являється, спочатку спробуйте інший USB-кабель. Для деяких плат може знадобитися драйвер USB-UART (CP210x або CH340 залежно від плати).

## 4. Запишіть файли через USB

Для першого запису використовуємо **esptool** — офіційну утиліту Espressif. Знати програмування або встановлювати Arduino IDE не потрібно.

1. Установіть [Python](https://www.python.org/downloads/), якщо його немає.
2. Відкрийте командний рядок або термінал **у папці з файлами прошивки**.
3. Установіть esptool:

   ```bash
   python -m pip install esptool
   ```

4. Введіть команду нижче, замінивши **PORT** на порт вашої плати, наприклад `COM4` або `/dev/ttyUSB0`:

   ```bash
   python -m esptool --chip esp32 --port PORT --baud 460800 write-flash --flash-mode dio --flash-freq 40m --flash-size 4MB 0x1000 bootloader/bootloader.bin 0x8000 partition_table/partition-table.bin 0xF000 ota_data_initial.bin 0x20000 wattpost_mini.bin
   ```

   Якщо `python` не працює, у Windows спробуйте `py`, а в Linux/macOS — `python3`.

5. Дочекайтеся повідомлення про успішне завершення. Якщо плата не перезавантажилася сама, натисніть **EN/RESET**.

**Не змінюйте адреси запису.** У WattPost застосунок починається з `0x20000`, а не з поширеної в інших проєктах адреси `0x10000`.

Якщо esptool не може під'єднатися до ESP32, спробуйте змінити швидкість `460800` на `115200`. Для деяких плат потрібно утримувати **BOOT** під час початку з’єднання й відпустити кнопку після його встановлення.

Не використовуйте `erase-flash`: повне стирання видаляє дані у Flash.

Офіційна довідка: [Espressif — Flashing Firmware](https://docs.espressif.com/projects/esptool/en/latest/esp32/esptool/flashing-firmware.html).

## 5. Налаштуйте Wi-Fi та JK BMS

Після першого запуску ESP32 відкриє власну Wi-Fi-мережу для налаштування:

1. На телефоні або комп’ютері знайдіть **`WattPost-XXXX`** (останні символи в кожної плати свої).
2. Під'єднайтеся до неї. Пароль мережі початкового налаштування в поточній прошивці — **`12345678`**.
3. Якщо майстер не відкрився автоматично, перейдіть на **http://192.168.4.1/**.
4. Виберіть домашній Wi-Fi, введіть пароль і дочекайтеся підтвердження підключення.
5. Майстер запропонує знайти **JK BMS** через Bluetooth. Виберіть потрібну BMS і дочекайтеся даних. Якщо вона зараз недоступна, можна завершити налаштування Wi-Fi та додати BMS пізніше.
6. Поверніться до домашнього Wi-Fi й відкрийте **http://bms.local/**. Якщо адреса не працює, використайте IP-адресу ESP32 із майстра налаштування або роутера.

Готово: показники та історія працюють **локально, без реєстрації та інтернету**. За бажанням додайте пристрій до [WattPost Cloud](https://wattpost.pp.ua) для віддаленого перегляду.

## Якщо виникли проблеми

- **Комп’ютер не бачить ESP32:** перевірте кабель передачі даних, USB-порт і драйвер USB-UART.
- **Помилка запису:** перевірте обраний PORT і чотири файли, зменште швидкість або скористайтеся кнопкою BOOT.
- **Не видно WattPost-XXXX:** перевірте живлення та чи завершився запис прошивки.
- **Телефон пише «Немає інтернету»:** для початкової мережі це нормально. Залишайтеся підключеними до неї й відкрийте `192.168.4.1`.
- **Не відкривається bms.local:** переконайтеся, що телефон у тій самій домашній мережі, або скористайтеся IP-адресою ESP32.
- **Не знаходить JK BMS:** перевірте, чи увімкнено її Bluetooth, чи акумулятор неподалік і чи не зайняте з’єднання іншим пристроєм.

WattPost лише відображає дані. **Не підключайте ESP32 до силових клем акумулятора:** захист акумулятора має забезпечувати сама BMS.
